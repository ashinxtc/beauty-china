# 独立同步服务与切换

独立 Worker：beauty-china-sync；唯一数据绑定 BEAUTY_SYNC 指向独立 BEAUTY_CHINA_SYNC KV。
不绑定 DAKA_SYNC，不请求旧服务，不修改 sync.daka-tool.top、打卡 Worker 或打卡数据。

2026-10-17：从旧 KV 只读枚举 sync:bc_ 前缀，并逐条检查 _app=beautifulChina 后复制到新 KV；原记录保留。实际执行结果以发布记录为准。新服务保留同步码和本机 bc_ 存储，支持 /、/ts、/bak。沿用既有同步码访问模式，未新增身份体系；KV 的最终一致性和旧客户端先合并后上传的并发限制仍然存在。

## 切换条件

1. 关闭所有答题页面的自动同步，并在各设备导出本地记录；打卡页面无需操作。
2. 核对旧源复制后是否有新增记录。只在新服务尚未接收用户写入时重新复制；不能盲目覆盖新服务。
3. 合并独立同步分支，等待网站发布。各答题设备刷新页面，确认请求新地址，先拉取合并再开启自动同步。
4. 对未刷新旧设备的新增数据，保留本地导出，通过答题应用现有合并逻辑处理；不要直接覆盖新云端快照。
5. 确认答题设备全部切换前，不能因打卡升级删除旧答题数据或关闭旧同步入口。

## 回退

前端切换前可直接暂停发布，新资源不会影响现有用户。切换后不可简单把地址改回旧服务：先暂停答题同步，导出新云端及各设备最新记录，合并验证后再决定恢复目标；旧 KV 是迁移时副本，不是持续更新的备份。任何回退均不得修改打卡数据或路由。
