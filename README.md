# 《美丽中国·版图小达人》随身刷题 App 使用指南

专为孩子备战**全国国家版图知识竞赛 / 美丽中国知识竞赛**量身定制的高效刷题与学习平台。

---

## 🌟 核心特色与功能

1. **零安装 · 纯离线秒开**：
   - 双击 [`启动刷题.bat`](file:///D:/AntigravityworkSpace/beautifulChina/启动刷题.bat) 或直接在浏览器中打开 [`index.html`](file:///D:/AntigravityworkSpace/beautifulChina/index.html) 即可开始做题。
   - 无需配置任何后端服务器，不依赖外网网络，完全本地离线运行。
2. **科学去重 · 刷一题少一题**：
   - 原始题量 **2,310 题**，智能去重后为 **1,521 题**（去重率高达 **34.2%**）。
   - 自动甄别出 **218 道超高频核心必考题**（标记 🔥 角标），重点优先攻克。
3. **跨终端云同步（数据方舟）与多孩子独立档案**：
   - ☁️ **跨设备实时互通**：输入家庭同步码（如“辰辰一家”或“myfamily888”），即可在手机、平板、电脑间实时互通全部刷题记录、错题本与模考成绩。
   - 🔒 **严格项目数据隔离**：自动采用 `bc_` 专属命名空间隔离，复用成熟云端架构的同时，**绝不与打卡工具 (`daka-tool`) 或其他项目产生任何数据覆盖或干扰**。
   - 🧒 **多孩子一键切换**：支持登记多个孩子（如大宝、辰辰），各自拥有独立的答题记录、错题本、收藏夹、进度与专属勋章，点击顶部头像即可秒级无缝切换。
4. **七大题库自由切换**：
   - ⭐ **全库去重纯享版 (1521题)**：推荐主刷，无任何重复题，性价比最高。
   - 🧒 **小学组官方样题 (267题)**：带 100% 官方标准答案，适合少儿/起步。
   - 🧑 **中学组官方样题 (268题)**：带 100% 官方标准答案，进阶培优。
   - 📜 **历年真题模拟汇编 (632题)**：带 100% 官方标准答案，强化综合常识。
   - 🏆 **2025大赛新赛题 (1143题)**：2025最新大赛综合真题包。
   - 🗺️ **地图识图专项攻坚 (247题)**：专攻看图认省份、海域划界、卫星照、岛礁图等关键拉分题型。
   - 🔥 **多题库高频必考核心 (218题)**：跨题库多次出现的金牌必考题。
4. **多样化练习模式**：
   - 📝 **顺序刷题**：逐题巩固，自动保存上次刷题题号，支持【做题模式】与【背题速记模式】自由切换。
   - ⚡ **20题速刷**：碎片化时间快速挑战，答完即出星级报告单。
   - ⏱️ **全真模考**：50 题限时 30 分钟，自动倒计时交卷并生成详细等级评价。
   - ⚔️ **错题消灭战**：所有做错的题自动收录；在错题本中**连续答对 2 次自动消灭**，高效攻克薄弱环节。
   - ⭐ **星标收藏夹**：难点知识点一键点亮收藏，随时专项回顾。
5. **官方《国家版图知识手册》画册阅读器**：
   - 随时点击顶部 📖 或底栏【查手册】，打开自然资源部官方 39 页全彩高清画册。
   - 支持按目录（国家版图定义、中国海域、南海诸岛十段线、台湾省表达规范等）快速跳转阅读。
6. **少儿友好激励机制**：
   - 触控大按钮、护眼柔和色彩（支持 🌙 护眼暗黑模式与 ☀️ 明亮模式一键切换）。
   - Web Audio 柔和正向音效反馈（可选静音）。
   - 满分/通关彩带撒花动画，配有 4 大备赛荣誉勋章（初出茅庐、测绘小达人、错题消灭勇士、版图金牌卫士）。

---

## ⌨️ 电脑端快捷键支持

* **选项选择**：按键盘 `A` / `B` / `C` / `D` 或数字键 `1` / `2` / `3` / `4`
* **下一题**：按 `Enter` 回车键 或 `→` 右方向键
* **上一题**：按 `←` 左方向键

---

## 📱 平板 / 手机使用方法

将整个 `beautifulChina` 文件夹拷入手机或平板，使用移动端浏览器打开其中的 `index.html`，即可全功能触屏刷题，支持手势轻触图片查看高清大图。
