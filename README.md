# 《美丽中国·版图小达人》随身刷题 App 使用指南

专为孩子备战**全国国家版图知识竞赛 / 美丽中国知识竞赛**量身定制的高效刷题与学习平台。

---

## 🌟 核心特色与功能

1. **零安装 · 纯离线秒开**：
   - Windows 下双击 [`启动刷题.bat`](启动刷题.bat)，或在浏览器中打开 [`index.html`](index.html) 即可开始做题。
   - 本地刷题无需后端服务器，可离线使用；跨设备云同步需要联网。
2. **科学去重 · 刷一题少一题**：
   - 原始题量 **2,310 题**，按完整题干、选项和配图整理为 **1,701 题**；孩子的题库只加载其中 **1,606 道有可用答案的题**。
   - 可刷题中有 **193 道跨题库高频题**（标记 🔥 角标）。其余 **95 题单独归档**，待确认后再加入。
3. **跨终端云同步（数据方舟）与多孩子独立档案**：
   - ☁️ **跨设备实时互通**：输入家庭同步码（如“辰辰一家”或“myfamily888”），即可在手机、平板、电脑间实时互通全部刷题记录、错题本与模考成绩。
   - 🔒 **严格项目数据隔离**：自动采用 `bc_` 专属命名空间隔离，复用成熟云端架构的同时，**绝不与打卡工具 (`daka-tool`) 或其他项目产生任何数据覆盖或干扰**。
   - 🧒 **多孩子一键切换**：支持登记多个孩子（如大宝、辰辰），各自拥有独立的答题记录、错题本、收藏夹、进度与专属勋章，点击顶部头像即可秒级无缝切换。
4. **七大题库自由切换**：
   - ⭐ **全库精选 (1606题)**：保留必要的选项或配图变体，全部可计分。
   - 🧒 **小学组样题 (264题)**：原文件解析出267题，停用3题。
   - 🧑 **中学组样题 (266题)**：原文件268题，停用2题。
   - 📜 **历年真题模拟汇编 (581题)**：原文件632题，停用缺图、冲突或选项异常的51题。
   - 🏆 **2025大赛题库 (1093题)**：原文件1143题，按用户提供的最终核对记录补齐参考答案，停用50题。
   - 🗺️ **地图识图专项 (337题)**：只加载有配图且有可用答案的题。
   - 🔥 **多题库高频题 (193题)**：跨题库出现且可计分的题。
4. **多样化练习模式**：
   - 📝 **顺序刷题**：逐题巩固，自动保存上次刷题题号，支持【做题模式】与【背题速记模式】自由切换。
   - ⚡ **20题速刷**：每轮独立作答，答完即出成绩报告；只抽取已有标准答案的题目，题量不足时按实际数量出题。
   - ⏱️ **全真模考**：最多 50 题、限时 30 分钟，支持手动交卷、超时交卷与原卷解析；后台同步不会重置试卷。
   - ⚔️ **错题消灭战**：各题库做错的题都会收录；点击“再答一次”可重复练习，**连续答对 2 次自动消灭**。
   - ⭐ **星标收藏夹**：难点知识点一键点亮收藏，随时专项回顾。
5. **官方《国家版图知识手册》画册阅读器**：
   - 随时点击顶部 📖 或底栏【查手册】，打开自然资源部官方 39 页全彩高清画册。
   - 支持按目录（国家版图定义、中国海域、南海诸岛十段线、台湾省表达规范等）快速跳转阅读。
6. **少儿友好激励机制**：
   - 触控大按钮、护眼柔和色彩（支持 🌙 护眼暗黑模式与 ☀️ 明亮模式一键切换）。
   - Web Audio 柔和正向音效反馈（可选静音）。
   - 满分/通关彩带撒花动画，配有 4 大备赛荣誉勋章（初出茅庐、测绘小达人、错题消灭勇士、版图金牌卫士）。

## ⌨️ 电脑端快捷键支持

* **选项选择**：按键盘 `A`—`F` 或数字键 `1`—`6`；按顺序填空的题须依次点击选项，界面显示每个选项对应的空位。
* **下一题**：按 `Enter` 回车键 或 `→` 右方向键
* **上一题**：按 `←` 左方向键

---

## 📱 平板 / 手机使用方法

将整个 `beautifulChina` 文件夹拷入手机或平板，使用移动端浏览器打开其中的 `index.html`，即可全功能触屏刷题，支持手势轻触图片查看高清大图。

## 云端 / Linux 启动与验证

在项目目录运行：

```bash
python -m http.server 8000
```

通过环境的端口预览打开 8000 端口；本机使用 `http://localhost:8000`。应用无需安装 Node 依赖或执行构建。

同步逻辑回归测试使用 Node.js 18 或更新版本：

```bash
node tests/sync.test.js
```

浏览器测试使用 Python、Playwright 与 Chromium，覆盖桌面、手机和平板尺寸；同步请求由模拟服务处理：

```bash
python -m pip install -r requirements-test.txt
python -m playwright install chromium
python -m unittest -v test_app test_mobile_tablet
```

已有系统 Chromium 时会自动使用；也可以通过 `TEST_BROWSER_PATH` 指定浏览器可执行文件。

## 题库答案与同步说明

- 孩子的全库由 **690 题增加到1606题**。另有 **95题停用**：47题原资料缺图、7题选项异常、3题原资料答案冲突、38题核对记录仍有疑问。停用题不加载到刷题数据，也不会从旧收藏夹或错题本重新进入练习。
- 2025 原始题库没有配套答案表。现根据[用户提供的共享核对记录](https://chatgpt.com/share/6ace5f64-980c-83ec-8291-b563c930cefc)恢复全部1143题的答案处理结论，其中1098题的参考答案可采用，45题仍需核验；再剔除5道重复选项异常题，实际可刷 **1093题**。
- 三个 AI 答案一致不等于官方确认。本次以最后的更正和逐题核对记录为依据，并继续停用“待核／拟答”题；答案解析中保留出处与必要的旧称、旧法、年份说明。
- 孩子的页面不再提供“待核验题”入口。家长可查看 `answer_review.csv` 或 `pending_questions.json`；已导入的2025题号、参考答案与解析汇总在 `confirmed_answers_2025.csv`。
- 错题本、收藏夹和统计保留各来源题目的原始编号，因此旧的分题库记录仍可使用。同一题在全库与来源题库中分别作答，会分别保留记录。
- “立即双向合并”和自动上传会先读取云端，再合并并上传；“从云端拉取合并”只执行拉取合并；“上传覆盖云端”保留原有的确认操作。
- 答题、收藏、进度和错题状态按更新时间合并；删除档案和重置进度有独立标记，防止较旧的数据恢复已删除内容。旧记录没有更新时间时无法还原历史操作先后，建议所有设备使用更新后的版本。
- 断网时继续在本地保存记录；网络恢复后，自动轮询或页面重新获得焦点会重试尚未上传的数据。关闭自动同步会停止轮询和待执行的自动上传，手动同步仍可使用。
- 本仓库只包含客户端，测试验证的是模拟服务下的行为。现有服务使用整份数据读写，多台设备在同一时刻上传仍需服务端条件写入支持才能保证原子合并；真实服务兼容性需要另行联调。

## 题库审计与补充答案

本轮确认并修正了以下答案字母错误：中学组第 117 题 B → C；2025 第 326 题 D → B、第 587 题 C → D、第 1029 题 A → B。中学组第 234 题的四个选项已从错误拆分的七条中恢复。

原始资料中“大陆与台湾第一次接触的时期”“陕西与山西的界线”“澳门城市地图图名”三组同题答案互相冲突，已暂停计分。历年题库中的 47 道识图题缺少原图，不能用同题干的其他地图随意替代。完整检查记录见 `question_audit.json`，待补充清单见 `answer_review.csv`。

共享记录的最终更正已落实：2025第11题选ABCDE、第19和425题选D、第787题选A；第696题无准确组合，停用。第379、391、611、902等仍待核，不采用早期拟答。逐题记录还明确更正了第159题为A、第697和1130题为A。第4、17、37题按填空顺序评分，尤其第17题是C→B。

原Word解析程序只识别A—D，导致E、F被拼接到上一选项；现在完整解析A—F及段内换行。原题第808题的F文字本身重复了标号，页面显示时去除多余标号。

缺少答案的题可通过 2025 题库配套答案、官方资料或已有题库中经人工核验的同题逐项补充。模糊相似匹配只输出候选，不会自动变成计分答案。`answer_overrides.json` 保存已核对题干、选项与参考题的补充记录；新增记录须保留证据，核验后再重新生成数据。

`reviewed_answers_2025.json` 保存共享核对记录恢复的逐题结论，并绑定原DOCX校验值、题干、选项和配图。重新生成不会丢失本次导入；源文件变化时停止导入，要求重新核对。`recover_shared_answers.py` 只读取共享记录中的字面量答案表，不执行其中的脚本；最后一条结论优先于中间报告，例如第902题最终保留待核。

```bash
python -m pip install -r requirements-data.txt
python audit_questions.py
python -m unittest -v test_question_bank
```

`python parse_and_compare.py` 可以重新从原文件提取，再走相同的核验流程；两个入口都会同步更新 `questions_data.js` 和 JSON 文件。小学组 PDF 在第 11 题后直接跳到第 13 题，虽然答案表有第 12 题，但没有对应题干，所以未编造补入。中学组图片答案表由 `source_answer_keys.json` 保存经核对的值并绑定 PDF 校验值，原 PDF 更新后需重新核对。

`legacy_question_index.json` 保留原有题号定位，`bank_progress_migrations.json` 保存升级前的索引顺序。新的进度记录同时保存题目编号和题库版本；移除题目后按编号恢复进度，若该题已停用则继续到下一道可刷题。更新后建议重新练习本轮修正的题目；请让各设备加载更新后的题库与脚本。
